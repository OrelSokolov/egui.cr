Float & positioning

the engine has no float/position style keys (the flow is linear): floats are emulated by row order + reserved padding gutters, absolute/fixed/z-index by ui.overlay anchors.

float: left — text beside the block
Crystal
ECSS
EXML

The blue block is declared first in the row and this paragraph wraps beside it, line after line — the magazine drop-cap column. The engine's rows are linear, so the text keeps its own column and never reflows below the block (a CSS float wraps back to full width once past it).

engine: horizontal row + wrap — no float key

float: right — pinned into a reserved gutter
Crystal
ECSS
EXML

The right gutter is the paragraph's own right padding; the green block is pinned into it with an overlay anchor and the text wraps along the left — the flow never sees the block, like a CSS float taken out of the normal flow.

engine: label padding-right gutter + overlay(:top_right)

clear — the next block drops below
Crystal
ECSS
EXML

A floated pair — block and the text beside it. Whatever comes next starts below the pair, spanning the full width again: the engine's block flow clears by construction, no explicit clear is needed.

cleared block — below the floats, full width

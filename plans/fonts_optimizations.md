# Оптимизации шрифтов

Консолидированный план: всё шрифтовое из `plans/course-to-raven.md` (было §4),
`plans/TODO.md` (общий атлас + epoch + LRU) и обсуждения Raven-паритета
(2026-11-13). Эталон по устройству кэша — Raven `tmp/Raven/src/render/font.c`.

## Что уже стоит (не трогаем)

- Кэш глифов `{glyph id, size}` → слот атласа (`src/egui/driver/text.cr`).
- Measure-кэш (LRU с clear-on-overflow) и kern-кэш.
- Ребейк on-demand после epoch-сброса атласа.

Этим закрывается steady-state: после прогрева текста кадр платит только
хэш-lookup на глиф. Всё ниже — про стоимость миссов, память и шину.

## Оптимизации (по приоритету)

### 1. Dirty-рект аплоад атласа — срочная

`GlyphAtlas#flush` (`driver/text.cr:380-388`) при каждом новом глифе льёт
ВЕСЬ буфер 2048×2048×RGBA = **16 МиБ** (`atlas_update(view_id, size, size,
@rgba)`). Один глиф 20×20 px = 16 МиБ по шине; скролл непрогретого текста
= 16 МиБ/кадр ≈ **~1 ГБ/с впустую**.

Решение: накапливать bounding-rect слотов, запечённых с прошлого flush, и
аплоадить только его (subimage-путь в шиме; Raven — `rvn_atlas_mark_dirty`,
`font.c:167`, аплоад только dirty-региона на UI-потоке). Полная заливка
остаётся только для `reset` (epoch-сброс) и первого создания текстуры.

Спека: `spec/shared_atlas_smoke.cr` / новый dirty-рект-кейс
(запечь глиф → flush → запечь ещё один → аплоад-рект не превышает
bounding-бокс новых слотов).

### 2. Квантизация размера глифа

Ключ кэша `{glyph id, size}` несёт неразмытый Float64: dpi-масштаб и
дробные размеры плодят почти-дубликаты глифов в атласе и бейках. Как Raven
(`font.c:751`): `size_q = round(size_px * 4)` (шаг 1/4 px, clamp 4..0xFFFF)
— size_q в ключ кэша, растер и выборка по нему.

Проверка: масштаб-переключение (zoom_spec-подобная сцена) не раздувает
заполнение атласа почти-дубликатами.

### 3. Общий атлас + epoch + LRU стеков (фаза 1, из TODO.md)

Проблема: «один атлас на файл шрифта» не масштабируется — 16 МиБ CPU +
16 МиБ GPU на каждый `AtlasFonts` независимо от числа глифов; кап
`EGUI_CR_MAX_ATLASES 16` в шиме (`backend/sokol_shim.c:609`) молча глушит
текст с 17-го шрифта; материализованные семейства живут вечно (~1.6+ ГиБ
на 50 шрифтов). Полный разбор — `plans/TODO.md` (секция про 200+ семейств).

1. **Один общий `GlyphAtlas` на бэкенд** (владелец — реестр, не стек):
   `AtlasFonts` держат ссылку. GPU-текстура одна, кап атласов перестаёт
   быть фактором. Размер 2048² (расти по высоте до 4096² при
   необходимости — как upstream egui).
2. **Epoch на атласе**: `reset` инкрементирует; `AtlasFonts#glyph` сверяет
   и чистит свой `@glyphs` при рассинхроне (иначе чужой reset оставит
   висячие UV).
3. **`reset_if_full` на уровне реестра**: после touch-прохода кадра один
   reset общего атласа + повторный touch ВСЕХ text-команд кадра.
4. **LRU материализованных стеков**: `last_used_frame` по факту кадра;
   сверх капа живых (напр. 64) — самый старый выкидывается из
   `@@materialized`/`@@named_fonts` с чисткой глиф-кэша; повторное
   обращение перечитает файл. Primary/mono не вытесняются.
5. Убрать O(stacks×cmds) в `text_cmds.select` (map стек → cmds за проход).

Затрагиваемые файлы: `src/egui/driver/text.cr`, `src/egui/driver/sokol.cr`
(paint_frame, fonts_for_cmd, materialize_font), `backend/sokol_shim.c`
(опционально `atlas_destroy`), спеки `spec/atlas_fill_dbg.cr`,
`spec/font_chain_smoke.cr`, `spec/font_fallback_spec.cr`.

Критерий: прокрутка 200+ семейств в widgets_gallery — текст не пропадает,
RSS/VRAM выходят на плато, возврат к показанному шрифту корректен.

### 4. Ring buffer глифов (фаза 2 — только при трэше)

Если фаза 1 даст трэш ресетов (ребейк экрана шрифтов на каждый reset при
скролле длинного списка): `last_used_frame` на каждый глиф, вытеснение
старейших с компакцией вместо полного wipe (схема Qt; upstream egui живёт
без неё). Не делать превентивно.

### 5. Асинхронность — только крупное и редкое

- Загрузка/парсинг файлов шрифтов при старте — прогреть на джобах/фиберах,
  чтобы первый кадр не платил мс за открытие файлов.
- SVG-растер — уже на джобах по курсу (`plans/course-to-raven.md` §2).
- **Растер глифов остаётся синхронным**: единицы-десятки мкс на глиф,
  нужны текущему кадру — асинхронность дала бы поп-ин текста при скролле
  виртуализированных списков. Raven делает так же (lock-free чтение кэша,
  миссы под мьютексом, `font.c:294`).

## Не-цели

- Не уходим со FreeType на stb_truetype: зависимость тяжелее, а схема
  кэша/атласа ортогональна растеризатору.
- Не SDF/MSDF-текст: битмап-глифы в квантованном размере достаточны
  (критерий — паритет с Raven, а не превзойти его).
- Не асинхронный растер глифов (см. §5).

## Критерии приёмки

- [ ] Аплоад атласа ≤ dirty-рект; полный — только reset/create.
- [ ] Ключ кэша глифов — квантованный размер; дубликаты от масштаба
      отсутствуют.
- [ ] Один атлас на бэкенд; 200+ семейств без пропадания текста, память
      на плато.
- [ ] Тихий кадр: 0 бейков глифов, 0 аплоадов (счётчик в EGUI_DRAW_STATS).

# Z-слои: резервная debug-полоса сверху — инспектор всегда поверх

> **Статус: план** (не реализовано).

## 1. Проблема

Инвариант «дебаг-инструмент всегда поверх всего» сегодня держится на магическом
числе: панель инспектора сидит на `z: 98` (`src/egui/inspector.cr:135`),
подобранном вручную под Foreground=99 (попапы/меню/модалки) и Tooltip=100
(`src/egui/layer.cr:15-30`). Это ломается двумя способами:

* любое **приложение**, открыв контекстное меню, модалку или тултип, рисует
  их поверх инспектора — они legitimately живут на z=99/100;
* приложение может само написать `painter.layer = 100` (клампится только в
  `MAX_LAYER_Z`) и перекрыть панель.

Конфликт — не внизу диапазона (базовый контент: панели Background=0, окна
Middle=50), а **на потолке**. Родитель-под-детьми уже работает порядком
записи внутри слоя (`src/egui/painter.cr:456`) — «базовый слой у parent-
виджета» проблему не решает. Решение — структурно недостижимая для приложения
полоса сверху, как `Order::Debug` в upstream egui (выше Tooltip).

## 2. Предлагаемая разметка

| Полоса | z | Кто |
|---|---|---|
| `Background` | 0 | панели |
| `Middle` | 50 | окна, `title_bar_tabs` (40), декорации окна (1) |
| `Foreground` | 90 | попапы/меню/модалки приложения (`POPUP_LAYER_Z`) |
| `Tooltip` | 95 | тултипы приложения |
| debug-полоса | 96..100 | только фреймворк (инспектор) |

Внутри debug-полосы:

* подсветка выбранного виджета — z=96 (сейчас `HIGHLIGHT_Z = 60`,
  `src/egui/inspector.cr:142`);
* панель инспектора — z=98 (`INSPECTOR_LAYER`);
* собственные попапы инспектора (pick menu, color picker, export modal,
  dock menu) — z=100; они рисуются в `after_update`, после всего контента
  приложения, так что порядок внутри полосы получается автоматически.

Хит-тесты следуют за z (`Memory#interact`), так что «поверх» выходит сразу и
для отрисовки, и для ввода — панель перехватывает мышь поверх app-попапов.

Следствия семантики слоёв:

* модалка приложения больше не блокирует инспектор (сейчас `Order::Middle`
  у панели оставляло эту дыру — блокировка модалками режет по слою ниже);
* собственный export-modal инспектора по-прежнему затемняет его панель
  (100 > 98);
* тултипы приложения больше не всплывают над панелью — для дебаг-инструмента
  это желаемое поведение.

## 3. Шаги

1. **`src/egui/layer.cr`**
   * добавить `Debug` в `enum Order` (после `Tooltip`), `z`-таблица:
     Background=0, Middle=50, Foreground=90, Tooltip=95, Debug=100;
   * `Foreground` → `POPUP_LAYER_Z` переименовать/переопределить как 90,
     `Tooltip.z = 95`;
   * ввести `APP_MAX_LAYER_Z = 95`: кламп приложения — `LayerId#initialize`
     и `Painter#layer=` клампят в `[0, APP_MAX_LAYER_Z]`, если order ≠
     `Debug`; для `Order::Debug` — в `(APP_MAX_LAYER_Z, MAX_LAYER_Z]`;
   * `MAX_LAYER_Z` остаётся 100 — настоящая вершина.

2. **`src/egui/inspector.cr`**
   * `INSPECTOR_LAYER` → `LayerId.new(Order::Debug, Id.from("inspector_panel"))`
     (z по умолчанию 98 — задать явно, см. п.1: Debug-полоса с внутренним
     порядком 96/98/100);
   * `HIGHLIGHT_Z` 60 → 96;
   * собственные попупы инспектора (`PICK_MENU`, `COLOR_POP`, `EXPORT_POP`,
     `DOCK_MENU`) — `Order::Debug`, z=100.

3. **`src/egui/context.cr`** — попапы/модалки приложения
   (`#popup`/`#modal`/меню: строки ~1163, 1222, 1381) остаются на
   `Order::Foreground` — переезжают на 90 автоматически через `Order#z`.

4. **Косметика после переезда**
   * обновить комментарии у `POPUP_LAYER_Z` (`src/egui/layer.cr:11-13`),
     `window_frame.cr` (`POPUP_LAYER_Z - 1` — сдвинется сам, комментарий
     проверить), `inspector.cr:129-142`;
   * явные z в кодовой базе (`title_bar_tabs` 40, `window_frame` 1) ниже
     Foreground — не затрагиваются.

5. **Проверка**
   * `crystal spec spec/inspector_spec.cr spec/overlay_spec.cr
     spec/menu_spec.cr spec/context_menu_spec.cr spec/overlay_spec.cr`;
   * вручную: инспектор поверх открытого контекстного меню/модалки/тултипа
     приложения; pick menu и color picker — поверх панели; export modal
     затемняет панель; ввод в панель работает при открытом app-попапе.

## 4. Альтернативы

* **Кламп без нового Order** — просто резать app-z ниже инспектора: работает
  для краски, но `order` участвует в групповых правилах (блокировка
  модалками, закрытие попапов по клику мимо), и инспектору нужна своя
  группа — именованный `Order::Debug` чище.
* **Базовый слой у корневых виджетов** — не решает ничего: конфликт на
  потолке диапазона, а не на дне.

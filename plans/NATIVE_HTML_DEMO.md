# NATIVE_HTML_DEMO — порт raven_music 1 к 1

Записано 2026-11-10. Цель: воспроизвести пример `examples/music`
библиотеки Raven (Apache-2.0, клон в `tmp/Raven`) на egui.cr один к
одному — как флагманское демо NativeHTML. Критерий успеха сформулирован
владельцем: «такая же плавность и красота». Плавность — отдельный трек
(§4), потому что FPS у нас уже сопоставимый, а разница — в стабильности
края при субпиксельном движении, present mode и pacing'е кадров.

Референс: `tmp/Raven/examples/music/` — `main.c` (1108 строк: окна,
страницы, плеер), `library.c` (377: 24 выдуманных альбома, ~320 треков,
6 плейлистов, обложки), `tags.c` (420: кастомные теги), `ui/*.xml`
(713 строк, 11 файлов), `themes/*.xml` (4 файла).

## 1. Что представляет собой оригинал

**Приложение** (без звука — «проигрывание» имитируется часами):

- Окно 1360×860, CustomHeader; Overlay: снизу анимированный фон
  `Effect="mesh"` (градиент в цветах играющей обложки), поверх —
  полупрозрачные панели: sidebar, центральный Switcher из 5 страниц
  (Home / Collection / Search / Library / Settings), панель Now Playing,
  нижний бар плеера.
- **Island** сверху: свёрнутый — «что играет» + мини-визуализатор;
  раскрывается при наведении (ExpandOnHover) в мини-плеер; на MacBook
  живёт в notch (Notch="true").
- Строки/карточки (TrackRow, AlbumCard, QuickCard, Chip, NavItem…) —
  компоненты `widgets.xml` с параметрами: `{Glyph}`, тернарники
  `{Active ? 'chip on' : 'chip'}`, условия `If="{!empty(Action)}"`.
  Инстансы создаются из XML-строк (`Rwidget_create_from_xml`), пул на
  64 строки с переиспользованием.
- **Кастомные теги приложения** (`Rxml_register_tag`): `<Icon>` —
  векторный глиф цветом текста; `<Cover>` — обложка со скруглением,
  `Album="current"` следует за играющим; `<Visualizer>` — кастомный
  painter (танцующие бары, `Rcustom_set_paint_callback` + `Rdraw_rect`
  с радиусом); `<Heading>` — bold-label.
- **Плеер**: очередь, shuffle, repeat off/all/one, позиция по часам,
  тикер 0.25 с (Rtimer), notice-система (заголовок island подменяется
  на 2.5 с), громкость/mute.
- **Акцент темы следует за обложкой** (`Rtheme_set_accent` из двух
  доминантных цветов обложки; на светлой теме — затемнение 0.62).
  Обложки без jpg рисуются процедурно.
- **Настройки**: эффект фона (mesh/aurora/plasma/spotlight/shimmer —
  5 GPU-шейдеров), «следовать за обложкой», «анимировать фон» (выкл —
  окно красит только при изменениях), панель Now Playing.
- **Темы**: 3 собственных (Nocturne, Aurora glass, Daylight) + 16
  встроенных луков Raven (вкл. glass-варианты с blur, Windows 11,
  macOS 26, GNOME, high contrast).
- **Анимации повсюду** (`widget/anim.c`, §3.2): hover/нажатие/
  скроллбары — paint-пружины; карточки и страницы — Appear-переходы
  со стэггером; island и панели — layout-пружины; закрывающиеся
  попапы — ghost; reduce-motion выключает всё.
- Горячие клавиши: Space, Ctrl+←/→, Ctrl+L/F/P, Alt+← (назад по
  истории страниц).

с атрибуцией; обложки — свои (процедурные) либо свои jpg.

## 3. Дыры фреймворка, которые надо закрыть

По убыванию визуального эффекта. Оценки — грубые.

### 3.1 SDF-примитивы (та самая плавность)

Стабильный край при субпиксельном движении: у нас тесселяция (AA
пересчитывается — края мерцают на медленных анимациях), у Raven —
аналитический SDF в `ui.frag` (Apache-2.0, прецедент). План: свой
шейдер-пайплайн в sokol (GL3 тянет, Vulkan не нужен), для набора
rect/rounded/border/shadow/glyph — квад с flat-атрибутами вместо
треугольников. Попутно: paint list худеет, градиенты и радиусы —
параметры инстанса. Это же закрывает Canvas2D Route B (§4.3
NativeHTML) проще тесселяции.

Инфраструктурный прецедент уже в шиме (проверено 2026-11-10):
кастомные пайплайны существуют (`text_pipeline`, `g_pip_3d` с depth,
`g_replace_pip` — все через `sgl_make_pipeline`), а `Mesh3DCmd` —
готовый образец «типизированная команда paint list → свой entry-пойнт
`egui_cr_mesh3d` в шиме». SDF добавляется по той же схеме: `SdfCmd`
батчем + `egui_cr_sdf_batch` + шейдер (GL3 instancing есть в GLCORE).
Текст остаётся на атласе (как у Raven — `PRIM_GLYPH` сэмплирует
атлас тем же пайплайном). Оценка: 1–2 недели.

### 3.2 Spring-слой анимаций («живость» Raven)

Модель Raven (`tmp/Raven/src/widget/anim.c`, 319 строк; раздел Animation
в docs/ARCHITECTURE.md): **пружина** — затухающий осциллятор (значение +
скорость + цель, интегрирование фиксированным подшагом; параметры —
период и ζ). Пресеты: `SMOOTH` 0.30с/ζ=1.0, `BOUNCY` 0.38/0.52,
`WOBBLY` 0.50/0.32. На пружине стоят три механизма:

1. **Paint-пружины** — пружина живёт внутри paint-функции виджета и,
   пока движется, сама просит следующий кадр. Hover, нажатие, свитчи,
   выделение, скроллбары, визуализатор. Скорость непрерывна:
   прерывание не рождает скачка (easing-кривая при рестарте — скачет;
   это ключевая разница «ощущения живости»).
2. **Appear-переходы + стэггер** — появляющемуся виджету даётся
   состояние (тип, старт, задержка `AppearDelay`), инстансы
   трансформируются **постфактум** (`rvn_drawlist_transform`:
   scale/offset/opacity вокруг pivot) — layout не участвует, соседи и
   хит-тест видят виджет на месте с первого кадра. Именованные:
   Fade/Pop/Zoom/Fly×4/Drop/Slide.
3. **Layout-пружины** — прямоугольник виджета догоняет выданный
   layout'ом (island, панели).

Плюс: **ghost** закрывающегося попапа (рисуется, сжимаясь в
открывашку, пока пружина не успокоится); `Rset_animation_time_step`
(детерминизм для тестов/скриншотов); `Rset_animations_enabled(false)`
(reduce motion, доступность).

Порядок порта: spring-примитив (общий, ~день) → paint-пружины на
hover/press/selection → Appear + transform инстансов (после SDF §3.1
тривиально: квад с flat-атрибутами × матрица; попутно закрывает
`transform`-анимации §7 NativeHTML без полного 2D CTM) → layout-пружины
island/панелей → ghost попапов → reduce-motion/time-step. Оценка:
1–1.5 недели суммарно, поверх SDF.

**Интеграция в словарь/ECSS** (решение): НЕ новые атрибуты на теги, а
новые значения существующей машины:

- `transition: background spring(bouncy)` — spring заменяет пару
  duration+easing; каскад/классы/`:hover` работают как раньше, меняется
  только интерполятор. Состояние пружины (скорость) — в Memory виджета
  по id анимации, шагает StyleAnimations. Пресеты: `spring(smooth)`,
  `spring(bouncy)`, `spring(wobbly)`, `spring(response, damping)`.
- `appear:` + `appear-delay:` — два новых свойства ECSS (в каскаде):
  `appear: fly-right` и стэггер `appear-delay: 0.08s`. Тема задаёт
  глобально (Aurora анимирует карточки, Daylight — `appear: none`),
  reduce-motion форсит `none`. Семантический аналог браузерного
  `@starting-style`; в SPEC.md как честное расширение контракта.
  Атрибуты Raven `Appear`/`AppearDelay` маппятся сюда один к одному.
- Paint-пружины hover/press/скроллбаров — дефолты движка внутри
  виджетов, в разметке не видны (тюнить пресетом из темы — потом).
- Layout-пружины и ghost попапов — поведение движка, без ECSS-параметров.

### 3.3 Фоновые GPU-эффекты (mesh/aurora/plasma/spotlight/shimmer)

Полноэкранный квад + фрагментный шейдер с time-uniform в цветах
обложки; «Animate» выкл → статичный кадр, окно красит только при
изменениях. В paint list — `EffectCmd` (прецедент расширения:
`Mesh3DCmd`). В Raven: `src/render/vulkan/shaders/effects/`. Оценка:
2–4 дня на инфраструктуру + 5 шейдеров.

### 3.4 Glass / backdrop blur

Захват фона под панелью + blur-проход + полупрозрачная панель.
Самый дорогой кусок после SDF (у Raven — `vk_glass.c`, отдельный
проход). Для демо достаточно одного уровня (панель surface поверх
эффекта). Оценка: неделя, только после 3.1.

### 3.5 Динамический акцент темы

`ctx.theme=` сегодня статичен; нужен accent-оверрайд (одна переменная
в resolver'е каскада) + перекраска на лету. Оценка: 1–2 дня.

### 3.6 Параметризованные exml-компоненты

Проверено 2026-11-10 — большая часть УЖЕ есть в `exml.cr` (1476 строк):
интерполяция `{name}` из store (`Runtime#interpolate`), `bind=`,
компоненты с props (атрибуты use-site → props, `seed_props`),
`<partial id>`/`<use partial>` (аналог Raven `<Include>`, parse-time),
структурные `if`/`unless`. Осталось: тернарники
`{Active ? 'chip on' : 'chip'}` и функции типа `empty()` в
интерполяции — мини-набор над store, не expression engine (границы
§10 NativeHTML соблюдаются). Оценка: ~день.

### 3.7 Реестр кастомных тегов

Проверено 2026-11-10 — механизм ЕСТЬ: неизвестное имя парсится как
`Kind::Custom` и диспатчится в хендлер, зарегистрированный на
рендерере (`Renderer#on`) — ровно `Rxml_register_tag`. Для демо это
не работа фреймворка, а сами хендлеры: `<Icon>`, `<Cover>`,
`<Visualizer>` (painter-виджет, танцующие бары), `<Heading>`.
Оценка: 1 день на хендлеры демо.

### 3.8 Island

Overlay-слой поверх всего, ExpandOnHover, привязка к верху окна.
Notch — macOS-only, отдельно и потом (на Linux-дев-машине не
проверить). Оценка: overlay — 2–3 дня.

### 3.9 Present mode + pacing (задержка ввода)

- MAILBOX при `BACKEND=vulkan` (шим наш, выбор режима — несколько строк);
  GLCORE оставляем как есть.
- Очередь из 2 кадров + копия paint list в пакет (back-pressure,
  модель Raven) — инженерная работа в шиме, после 3.1.

## 5. Критерии готовности

- Видеозапись 240 fps (телефон) рядом с оригиналом: визуализатор,
  seeker-слайдер, раскрытие island, смена страниц — без видимой
  дрожи краёв там, где у оригинала её нет.
- Пружины: hover-качели по кнопкам подряд (прерывание на середине) —
  без скачка значения; ghost закрытого попапа до успокоения;
  `Rset_animations_enabled`-аналог (reduce-motion) глушит всё разом.
- Статистика кадров (оверлей): p99 frame time ≤ 17 мс при
  анимируемом фоне; при «Animate» выкл — 0% CPU (план
  0percent_cpu.md).
- Скриншоты страниц попарно с оригиналом (тот же размер окна) —
  в `screenshots/music/`.
- capybara-спеки: навигация по 5 страницам, play/next/like/shuffle,
  смена темы/эффекта, follow-cover акцент.
- `crystal spec` зелёный; бинарь запускается из `bin/music`.

## 6. Не-цели

- Звук настоящий (у оригинала нет; minaudio — отдельным решением).
- Notch на macOS до момента, когда есть машина для проверки.
- Pixel-perfect: цель — визуальная паритетность, не совпадение
  байт в байт.
- 16 встроенных луков Raven: сначала свои 3 темы; портирование
  Windows 11 / macOS 26 — после, у нас уже есть gnome/macos-темы.
- Retained-дерево и параллельная покраска Raven — вне скоупа демо
  (immediate mode + on-demand repaint достаточно для этой сцены).

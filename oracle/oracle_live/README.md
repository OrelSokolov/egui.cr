# Raven Music — oracle live

Анимированный HTML-оракул на Vue 3: то же окно 1360×860 и та же верстка, что в
статическом оракуле `../raven_music/`, но интерактивно — поведение портировано из
C-приложения Raven (`tmp/Raven/examples/music/{main.c,tags.c,library.c}`).

Открыть `index.html` в браузере (офлайн: Vue лежит рядом, `vue.global.prod.js`).

## Что живого

- **плеер** — ходит по часам: позиция, seek-слайдер, конец трека → следующий;
  `repeat off/all/one`, `shuffle` (перемешивание очереди как `play_list`),
  `prev` (>3 с — в начало трека, иначе предыдущий);
- **визуализаторы** (`<ra-vis>`) — точный порт `fake_level` из `tags.c`: бит
  каждые полсекунды, атака 22 / спад 9, на паузе уровень 0.08;
- **акцент и фон из обложки** — `make_accent` из `library.c` (s 0.45..0.85,
  v 0.78..0.98); пятна фона — цвета обложки ×0.55/×0.35, эффекты
  Mesh/Aurora/Plasma/Spotlight/Shimmer/None + «Animate the background»;
- **остров** — свёрнут показывает трек/уведомления (2.5 с), при наведении
  разворачивается в мини-плеер (`island.xml`);
- **очередь** — «Next in queue» до 4 строк, прыжок по клику; контекст «From …»;
- **лайки** — треки и альбомы, «Liked songs» — живой плейлист;
- **поиск** — живой фильтр (альбомы/артисты/жанры + до 5 песен + top result),
  плитка жанра запускает поиск;
- **коллекция** — альбом и плейлист (мета «N songs, M min s», колонка Album
  только у плейлиста, как `fill_collection_rows`);
- **клавиши** — Space, Ctrl+←/→, Ctrl+L, Ctrl+F, Ctrl+P, Alt+←.

Расхождения со статическим оракулом — намеренно, в пользу C-приложения:
карточки не сминаются флексом (страницы скроллятся, как ScrollBox), в панели
now playing виден визуализатор и 4 строки очереди.

## Файлы

- `index.html` — шаблон Vue (in-DOM), иконки-символы;
- `app.js` — данные (тот же кураторский набор, что в статике) + логика;
- `style.css` — база `raven_music/style.css` + интерактив/анимации;
- `vue.global.prod.js` — Vue 3.5 (vendored).

## Отладка

`index.html#…` задаёт стартовое состояние (аналог env у `main.c`):
`#album`, `#playlist`, `#search`, `#genres`, `#library`, `#settings`,
опционально `,paused`, `,island` (остров развёрнут), `,dump` (дамп геометрии
в `<pre id="geo-dump">` — использовался для сверки со статическим оракулом).
